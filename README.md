Smartphone Usage Analysis:
Project Overview:
This project analyzes smartphone usage data using Microsoft Power BI. The goal is to understand how people use smartphones, identify usage patterns, and present meaningful insights through interactive data visualizations.
The project uses a dataset containing smartphone usage-related information and converts the raw data into an easy-to-understand Power BI dashboard.

Objectives:
Analyze smartphone usage patterns.
Understand daily smartphone usage behavior.
Compare usage across different categories.
Identify important trends and patterns in the data.
Create interactive charts and visualizations.
Present useful insights through a Power BI dashboard.

Tools and Technologies:
Microsoft Power BI – Data cleaning, analysis, visualization, and dashboard creation.
CSV/Tabular Dataset – Source data for the analysis.
Power Query – Data transformation and cleaning.
DAX – Creating calculated measures and analysis where required.

Dataset:
The project uses smartphone usage data containing information related to users and their smartphone activity.
Typical data fields may include:
User information
Age or demographic details
Daily smartphone usage
App usage
Screen time
Social media usage
Other smartphone-related activity
Note: The exact columns depend on the dataset used in the Power BI file.

Project Workflow:
Collect the smartphone usage dataset.
Import the data into Power BI.
Check the data types and data quality.
Clean and transform the data using Power Query.
Create required calculated columns or measures using DAX.
Select suitable charts for different analysis requirements.
Create an interactive dashboard.
Analyze the visualizations and identify important insights.
Present the final findings using the Power BI report.

Dashboard:
The Power BI dashboard is designed to provide a clear view of smartphone usage behavior.
Possible visualizations include:
KPI cards
Bar charts
Column charts
Pie/Donut charts
Line charts
Tables
Slicers and filters
These visuals help users compare values, identify trends, and explore the dataset interactively.

Key Analysis Areas:
The analysis focuses on questions such as:
How much time do users spend on smartphones?
What are the common smartphone usage patterns?
Which categories or activities have higher usage?
How does usage vary between different user groups?
Are there noticeable trends in smartphone activity?
What insights can be obtained from the overall usage data?

Expected Outcome:
The completed Power BI report provides a visual summary of smartphone usage and helps users understand the major patterns in the dataset.

The project demonstrates basic skills in:
Data preparation
Data analysis
Power BI visualization
Dashboard design
Data interpretation
Reporting

How to Open the Project:
Install Microsoft Power BI Desktop.
Open the .pbix file.
Refresh the data if the source dataset is available.
Navigate through the report pages.
Use slicers and filters to interact with the dashboard.
Review the charts and insights.

Project File:
smartphone.pbix – Main Power BI project file.

Conclusion:
The Smartphone Usage Analysis project demonstrates how raw usage data can be transformed into meaningful visual information using Power BI. The interactive dashboard makes it easier to 
identify usage patterns, compare different categories, and communicate insights clearly.
